# LeetCode 70: Climbing Stairs — Complete C++ Explanation

## 1. Understanding the Question

In this problem, we are given a number `n`, which represents the total number of stairs.

We can climb either:
- 1 stair at a time.
- 2 stairs at a time.

Our task is to calculate the total number of different ways to reach the top.

Important: We are counting the number of ways to climb the stairs, not the number of stairs themselves.

For example, if n = 3, there are 3 different ways:

Way 1: 1 + 1 + 1

Way 2: 1 + 2

Way 3: 2 + 1

Therefore, the answer for n = 3 is 3.

If n = 4, there are 5 different ways:

Way 1: 1 + 1 + 1 + 1

Way 2: 1 + 1 + 2

Way 3: 1 + 2 + 1

Way 4: 2 + 1 + 1

Way 5: 2 + 2

Therefore, the answer for n = 4 is 5.

Notice that every combination adds up to 4 stairs, but there are 5 different combinations.

The output is 5 because there are 5 ways to reach the top, not because there are 5 stairs.

## 2. Complete C++ Code

```cpp
class Solution {
public:
    int climbStairs(int n) {
        if (n <= 2) {
            return n;
        }

        int a = 1;
        int b = 2;
        int i = 3;

        while (i <= n) {
            int steps = a + b;
            a = b;
            b = steps;
            i++;
        }

        return b;
    }
};
```

## 5. Understanding the Main Logic

The important formula is:

ways(n) = ways(n - 1) + ways(n - 2)

Why do we use this formula?

To reach stair n, our last move must be one of these two possibilities:

1. We take 1 step from stair n - 1.
2. We take 2 steps from stair n - 2.

Therefore, the total number of ways to reach stair n is the number of ways to reach stair n - 1 plus the number of ways to reach stair n - 2.

For example, when n = 3:

ways(3) = ways(2) + ways(1)

ways(3) = 2 + 1 = 3

When n = 4:

ways(4) = ways(3) + ways(2)

ways(4) = 3 + 2 = 5

The answer is 5 because there are 3 ways that can be extended from stair 3 by taking one final step, and 2 ways that can be extended from stair 2 by taking two final steps.

Both groups reach stair 4, and the groups do not overlap.

This is why we add the two previous answers.

## 9. Why Do We Return b Instead of steps?

The original code contains:

```cpp
while (i <= n) {
    int steps = a + b;
    a = b;
    b = steps;
    i++;
}

return b;
```

We return `b` because it stores the final answer after the loop finishes.

But why not simply write:

```cpp
return steps;
```

There are two important reasons.

### Reason 1: Variable Scope

The variable `steps` is declared inside the while loop:

```cpp
while (i <= n) {
    int steps = a + b;
}
```

In C++, a variable declared inside a block `{ }` is only accessible inside that block.

Therefore, this code is invalid:

```cpp
while (i <= n) {
    int steps = a + b;
}

return steps;
```

The compiler will report an error because `steps` is not accessible outside the loop.

However, `a` and `b` are declared before the loop:

```cpp
int a = 1;
int b = 2;
int i = 3;
```

Therefore, they can still be accessed after the loop finishes.

### Reason 2: b Stores the Final Answer

Inside the loop, we write:

```cpp
int steps = a + b;
a = b;
b = steps;
```

After calculating the new answer, we copy it into `b`.

For n = 4, the final calculation gives:

steps = 5

Then:

b = steps

Therefore:

b = 5

When the loop finishes, `b` still contains 5.

That is why we write:

```cpp
return b;
```

### Can We Return steps Instead?

Yes, we can, provided we declare `steps` outside the loop.

For example:

```cpp
class Solution {
public:
    int climbStairs(int n) {
        if (n <= 2) {
            return n;
        }

        int a = 1;
        int b = 2;
        int i = 3;
        int steps = 0;

        while (i <= n) {
            steps = a + b;
            a = b;
            b = steps;
            i++;
        }

        return steps;
    }
};
```

This version works for the problem's valid inputs.

Here, `steps` is declared outside the loop, so it remains accessible after the loop ends.

For n = 4, the final value of `steps` is 5, so `return steps` returns 5.

Both versions work. The original version uses `return b` because `b` already stores the final answer.

## 11. Final Summary

Remember these points:

1. `n` represents the total number of stairs.
2. The function returns the number of different ways to reach the top, not the number of stairs.
3. `a = 1` represents the number of ways to climb stair 1.
4. `b = 2` represents the number of ways to climb stair 2.
5. `i = 3` means we start calculating from stair 3.
6. `steps = a + b` calculates the number of ways to reach the current stair.
7. `a = b` moves the previous answer forward.
8. `b = steps` stores the newly calculated answer.
9. `i++` moves the calculation to the next stair.
10. `while (i <= n)` repeats the calculation until we have reached the target stair.
11. `return b` returns the final answer.
12. `steps` cannot be returned outside the original loop because it is declared inside the loop. It can be returned if it is declared outside the loop instead.

The main formula is:

ways(n) = ways(n - 1) + ways(n - 2)

The main idea is that every way to reach stair n must end with either a 1-step move from stair n - 1 or a 2-step move from stair n - 2.

By adding the answers for those two possibilities, we calculate the total number of ways to reach the target.

Time Complexity: O(n), because the loop runs approximately n times.

Space Complexity: O(1), because we use a fixed number of variables, regardless of n.
