# Start here if you’re unsure

Upload new practice files here when you don’t know which topic fits yet. Rough notes and unfinished attempts are welcome.

While you’re in this folder, choose **Add file → Upload files**, upload your file, and commit. Give it a name you’ll recognize later, such as `two-sum-attempt.cpp` or `recursion-notes.txt`.

When the main idea becomes clear, move the file to its topic folder. Keep one copy, so you always know which version to revise.
